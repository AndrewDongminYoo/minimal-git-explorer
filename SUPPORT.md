# Support

Use GitHub Issues for bug reports and feature requests:

- Bugs: include VS Code version, OS, Git version, extension version, and the repository shape you tested with.
- Git errors: include the relevant lines from the **Minimal Git Explorer** output channel.
- Feature requests: keep them aligned with the local-first, read-first scope.

Do not include secrets, private remote URLs, access tokens, or proprietary patch output in public issues.
