# ADR-003 Summary: Parser Isolation

**Decision:** All git output parsers live in `src/git/parsers.ts` as pure functions with zero `vscode` imports.

**Why:** Makes parsers unit-testable without launching the VS Code Extension Host. Single responsibility per module.

**Enforcement:** `parsers.ts` and `gitTypes.ts` must never import from `vscode`.

Full ADR: `docs/notes/adr-003-parser-isolation.md`
