# ADR-001 Summary: Git CLI Only

**Decision:** Use `child_process.execFile` to spawn git. Do NOT use `vscode.extensions.getExtension('vscode.git')`.

**Why:** VS Code's git extension API is undocumented and unversioned. Pure CLI output is a plain string — parsers can be unit-tested without the Extension Host.

**Key safety rule:** Always pass args as arrays to `execFile`. Never concatenate into a shell string.
